# S10: 配对显著性检验 —— 主结果的统计可靠性复核

> 日期：2026-07-31 | 脚本：`s10_paired_test.py`（独立复跑）、`decompose.py`（矛盾拆解）
> **结论先行：三思路组合相对 Phase 6B 的 +0.31pt 增益在统计上不显著，且其符号对一个实现细节敏感。此前"+0.31，4 折全非负"的表述需要加上显著性限定。**

## 1. 为什么做这个检验

S5 pilot 的副产品发现：**单序列 IDF1 的 base-vs-ours 差值标准差达 2.63pt**（scene4 15 序列），远大于聚合增益 +0.31pt。这意味着聚合数字本身无法说明增益是否真实——必须做配对检验。

## 2. 两次检验给出相反符号（已定位原因）

| 检验 | 协议差异 | 逐序列 mean delta | 95% CI | 判定 |
|---|---|---|---|---|
| `s10_paired_test.py` | **每序列 reset 去噪器缓冲** | **−1.097** | [−2.016, −0.303] | ours 更差 |
| `decompose.py`（用主实验自身数据） | **跨序列复用缓冲**（主实验行为） | **+0.288** | [−0.627, +1.163] | 不显著 |

**原因不是加权方式**：主实验协议下，pooled delta = +0.31 与 unweighted per-seq mean = +0.288 高度一致，说明"长序列主导"不是问题。

**原因是去噪器缓冲状态**：`FTMDenoiser` 在主实验中每折只创建一次、**从不调用 `reset()`**（`v2_experiments.py:118`、`phase6b_integrated_mot.py:92`），因此每个序列开头 ~15 帧的滑窗里装着**上一个序列尾部的 FTM 值**，产生污染的去噪输出；而 reset 后这些帧回退为原始 FTM（`inference.py` 的 fallback 分支）。

- reset 更符合原则（序列间无状态泄漏）
- 但**方法优劣的符号随这一细节翻转** → 说明 +0.31 不是稳健增益

## 3. 主实验协议下的正式检验（apples-to-apples）

67 个序列配对（base = Phase 6B，ours = T15+T11+T3b，均为主实验代码路径）：

```
pooled delta            : +0.31 pt      （标准 MOT 协议，与 findings.md 一致）
unweighted per-seq mean : +0.288 pt     (std 3.699, SE 0.452)
sign                    : 42 正 / 24 负
bootstrap 95% CI        : [-0.627, +1.163]   ← 包含 0
Wilcoxon 双侧 p         : 0.1524             ← 不显著（α=0.05）
```

**逐序列 delta 的离散度极大**（std 3.70），最好与最差的序列相差 25pt：

## 4. 如实结论与对论文主张的修正

**必须修正的表述**：
- ❌ 原表述："三思路组合 88.22%（+0.31），4 折全部 ≥ 基线" —— 数字无误，但暗示了稳健改进
- ✅ 应改为："在标准 pooled 协议下取得 +0.31pt（4 折全非负）；但逐序列配对检验显示该增益不显著（Wilcoxon p=0.15，bootstrap 95% CI [−0.63,+1.16]），且符号对去噪器缓冲重置策略敏感。以当前数据无法断言优于 Phase 6B。"

**仍然站得住的结论**（效应量远超噪声）：
1. 完整管线相对纯视觉 OC-SORT 的巨大增益（65.63 → 87.91，+22.28pt）——这是原有工作的结论，不受影响
2. 异方差 σ̂ 去噪的**去噪质量**改进：4 折 MAE 全部降低（0.689→0.665 / 0.808→0.764 / 0.961→0.849 / 0.707→0.648），ANEES=1.05 校准良好，corr(σ̂,|err|)=0.378 —— 这些是直接测量量，不涉及 MOT 端噪声
3. 真实检测下无线信息价值近乎翻倍（+5.04 → +9.60/+12.23，S5）——效应量 5~12pt 远超单序列噪声 2.6pt
4. σ̂ 在 Gaussian 分支的 +0.91pt：**待同样检验**（`v2_gauss_perseq.json` 运行中）——效应量是 +0.31 的 3 倍，更有希望通过，但必须验证后才能声称

## 5. 后续必做

1. **完成 Gaussian 分支（+0.91）的配对检验** —— 这是思路 1 的核心 MOT 端证据
2. **统一去噪器 reset 策略**并重跑全部结果：建议采用 reset-per-sequence（无跨序列泄漏），这会改变所有绝对数字但消除该实现依赖
3. **扩大样本或改进方法**：67 序列 SE=0.45，要检出 +0.3pt 需 n≈600 序列（不现实）；更实际的方向是**把方法改到效应量 ≥1pt**，或转向真实检测场景（效应量更大）
4. 消融表的每一行都应附 CI 或 p 值，避免用 0.02~0.15pt 的差异排序组件

## 6. 方法学教训（值得写进论文）

MOT 数据集上 sub-1pt 的 IDF1 差异需要配对检验才能声称；单看 4 折平均或"全折非负"不足以排除噪声。本工作的逐序列 delta std 达 3.7pt，意味着**任何小于 ~0.9pt（1.96×SE）的聚合增益都可能是偶然**。这一点对 Vi-Fi 这类序列数有限（67 条）的数据集尤其重要。

## 7. Gaussian 分支 σ̂（思路 1 的 MOT 端主张，+0.91）→ **同样不显著**

`gaussian_sigma_test.json`，67 序列配对：

```
pooled: base 85.61 -> ours 86.52   delta +0.91
per-seq mean delta : +0.829 pt  (std 6.170, SE 0.754)
sign               : 36 正 / 28 负
bootstrap 95% CI   : [-0.676, +2.303]      ← 包含 0

```

效应量虽是 +0.31 的近 3 倍，但 Gaussian 分支的序列间方差更大（std 6.17），因此仍无法拒绝原假设。

## 8. ⚠️ 重大更正：去噪 MAE 的对比此前是无效比较

**此前报告**（findings.md / experiments_log.md R6、R12）："hetero μ 的 MAE 在 4 折全部优于 causal_cnn（0.689→0.665 / 0.808→0.764 / 0.961→0.849 / 0.707→0.648）"。

**该结论错误**，原因是**两者评测的帧集合不同**：
- `FTMDenoiserBatch.denoise_sequence` 对每个有效段的前 W−1=14 帧**回退为原始 FTM**；我当时用 `den[v]`（全部有效帧）统计 causal，把这些高误差的回退帧算进了 causal
- 而 hetero 只在窗口填满的帧上统计
- → causal 被不公平地惩罚

**同一帧集合下重测（仅窗口填满帧，n=278,407）**：

| fold | raw | causal | hetero | n_frames |
|---|---|---|---|---|
| scene1 | 1.4069 | **0.6524** | 0.6650 | 49,551 |
| scene2 | 1.4377 | **0.7572** | 0.7639 | 78,399 |
| scene3 | 1.7017 | 0.8536 | **0.8494** | 80,467 |
| scene4 | 1.3972 | 0.6536 | **0.6479** | 69,990 |
| **ALL** | | **0.7404** | 0.7419 | 278,407 |

**逐时序配对检验**（每序列每手机一条，n=185，`denoise_mae_test.json`）：
```
causal 0.7433  vs  hetero 0.7448
改进量 (causal−hetero) = -0.0014 m   CI [-0.0042, +0.0013]
hetero 更好的比例 = 77/185 = 41.6%
Wilcoxon p = 0.047（方向为 causal 略优）
```

**正确结论**：两个去噪器的**去噪精度实质等同**（差异 0.0015m，远小于 0.74m 的量级），causal 甚至略优。这也与判别度诊断一致（AUC 差异仅 ±0.004）——两者本就近乎等价。

**连带影响**：
- 思路 1 的价值**不在于把 μ 做得更准**，而在于：**在不损失去噪精度的前提下，免费获得一个校准良好的逐帧不确定度 σ̂**（ANEES=1.05，corr(σ̂,|err|)=0.378）。这仍是可验证的真实贡献，但表述必须改。
- 思路 3（双残差仲裁）的前提"两个去噪器局部互补"被弱化——它们几乎等价，可仲裁的空间比预想的小，这与其 MOT 增益不显著相吻合。

## 9. 更正后的证据清单

**仍然成立（直接测量，无需显著性检验）**：
1. σ̂ 校准质量：验证集 ANEES=0.968 → 温度 0.984；**测试集（跨场景）ANEES=1.052**
2. σ̂ 有效性：corr(σ̂, |真实误差|)=0.378；动态范围 p10 0.53 / 中位 0.77 / p90 1.14 m
3. 去噪本身相对原始 FTM 的巨大改进：1.40→0.74 m（−47%）——这是原项目 Phase 6A 的既有结论
4. 原项目主线结果不受影响：OC-SORT 65.63 → Phase 6B 87.91（+22.28pt）

**未能证实（不可作为论文主张）**：
1. ❌ 三思路组合优于 Phase 6B（+0.31，p=0.15，CI 含 0；且符号依赖去噪器 reset 策略）
2. ❌ σ̂ 自适应在 Gaussian 分支的增益（+0.91，p=0.199，CI 含 0）
3. ❌ hetero μ 去噪精度更优（同帧集合下实为持平/略差）
4. ⚠️ 真实检测下无线价值放大（S5，效应量大但 n=1 序列，仅为 suggestive）

**仍有价值的阴性结果**（方法学贡献）：T1 轨迹相关（离线 AUC 0.53 证伪）、T2 上报 std 自适应、T3a 遮挡代价调制（凸组合亦负）、T5、T7、T8 SPRT——均有明确失败机理分析。
